# Progetto-Settimana-2

Pagina web che imita la homepage di Amazon, fatta con HTML, CSS e JavaScript.

## Cosa contiene

- **Header** fisso in alto, con logo, barra di ricerca e menu
- **Hero** con il titolo delle offerte
- **Categorie**: 4 card (Elettronica, Libri, Abbigliamento, Casa)
- **I più venduti**: griglia di prodotti generata da JavaScript per il file progetto.html e in css per il progetto index.html
- **Footer** con 3 colonne di link

## File del progetto

- `index.html`: la struttura della pagina collegata a css e script.js

- `script.js`: la logica in JavaScript che fa rifermento alla pagina index.html

- `progetto.html` la struttura della pagina collegata a css e esercizioAvanzato.js

- `esercizioAvanzato.js`: la logica in JavaScript che fa rifermento alla pagina progetto.html

- `style.css`: lo stile di entrambe le pagine html(colori, layout a colonne con float)

## Cosa fa il JavaScript

- `prodotti`: array con 12 prodotti (nome, categoria, prezzo, rating, immagine, disponibile)
- `formattaPrezzo(prezzo)`: scrive il prezzo come "€ 19,99"
- `stelline(rating)`: trasforma il voto in stelle (★★★☆☆)
- `cat(categoria)`: mostra in console i prodotti di una categoria
- `filtro()`: crea un array con i prodotti disponibili
